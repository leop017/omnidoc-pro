# v0.1.1 — 修复 + CI 自动化

**OmniDoc Pro** v0.1.1 是在 0.1.0 基础上的修订版本，修复 Excel 解析的一个数据污染缺陷、补全 LLM 层测试覆盖，并为发布流程引入了 GitHub Actions 自动化。

## 修复（Bug Fixes）

- **Excel `Unnamed` 列名污染修复**（`omnidoc/engines/deep/_excel.py`）
  深度 Excel 解析原先以 `pd.read_excel` 默认 `header=0` 读取，会把首行当作列名；当首行存在空单元格时 pandas 会自动生成 `Unnamed: 0`、`Unnamed: 1` 等占位列名，随 Markdown / JSON 一起进入 RAG 嵌入层，造成噪声。
  本次改为 `header=None` 全量读取，并同步调整：
  - `_df_to_rows`：改用 `df.values.tolist()` 生成数据行
  - `_filter_merges_for_dropped_rows` / `_remap_merged_rows`：合并单元格坐标映射对齐新索引
  - `_generate_md_standard`：直接基于数据行构建 HTML 表格，消除多余空表头行
  - `_generate_json_data`：对 `Unnamed: N` / 纯数字列名做 `col_N` 兜底清洗

- **LLM 服务并发限流修复**（`omnidoc/ai/llm_service.py`）
  修正 `_run_bounded` 在 Python 3.11 下 `asyncio.run(asyncio.gather(...))` 的用法，改为在 `async def` 内 `gather` 后再 `asyncio.run`，修复受限并发批处理时的异常。

## 新增（Features / Test Coverage）

- **LLM 层 mock 测试**（`tests/test_llm_service.py`）：覆盖连接探测、图像描述、受限并发与优雅降级。
- **端到端集成测试**（`tests/test_smoke_integration.py`）：真实 xlsx / docx 文件跑完整 转换 → 清洗 → 分块 流水线。
- **Excel 构建器专项测试**（`tests/test_excel_builder.py`）：43 个用例，覆盖 `_df_to_rows`、`_prepare`、`_build_merged_map`、`_generate_json_data`、`_generate_md_standard`、`_escape_table_cells`、`_cell_attrs`、`load_sheets`、`build` 等。
- **GitHub Actions 发布自动化**（`.github/workflows/`）：
  - `release.yml`：push `v*.*.*` tag 自动 build（wheel + sdist）并创建 GitHub Release，自动附上 `RELEASE_NOTES/X.Y.Z.md`。
  - `publish-pypi.yml`：push `v*.*.*` tag 自动 `twine` 上传正式 PyPI。

## 文档（Documentation）
