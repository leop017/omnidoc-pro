# v0.1.3 — 发布测试门禁 + 代码清理

**OmniDoc Pro** v0.1.3 在 0.1.2 基础上，为 CI 发布流程增加了测试门禁，清理了配置中的冗余字段，并修正了文档与代码的一致性问题。

## CI / 发布流程

- **`test` 发布门禁**（`.github/workflows/release.yml`、`publish-pypi.yml`）
  两个 workflow 新增 `test` job（`ruff check .` + `pytest tests/ -v`），作为 `build` job 的 `needs` 前置依赖。测试不通过则阻断后续构建与发布，确保每次 tag push 都经过全量门禁。
- **`build` 依赖 `test`**：`needs: test`，测试失败时 sdist/wheel 不会构建、不会上传。

## 代码清理

- **`config.py`**：移除 4 个未使用的配置字段 `excel_read_only`、`pdf_page_size`、`large_file_size`、`max_rows`。
- **`release.py`**：修复 ruff lint 问题（f-string 无占位符、未使用的 `pp` 变量）。
- **`test_excel_builder.py`**：import 排序 + 变量命名清理。

## 测试

- **`test_contracts.py`**：断言已移除的死配置字段不再被导出。
- 全量测试通过：**281 passed, 6 subtests passed**。

## 文档

- **`README.md`**：移除过期的 Excel streaming 描述，版本号 `0.1.2` → `0.1.3`。
- **`RELEASE_NOTES/README.md`**：索引新增 0.1.3。

## 已知限制

- exe 仍为 Windows 构建（CLI / WebUI）；Linux/macOS 请通过 `pip install` 安装 Python 版本。
- LLM 增强功能需自行配置 API key（OpenAI / Ollama / 兼容 API）。
