# v0.2.2 — 部分成功语义修复 + LLM 增强后重分块 + 结构保留

**OmniDoc Pro** v0.2.2 是针对"部分成功"场景的状态语义修复与 RAG 一致性增强。基于全量代码二次深度评估，修复了 2 个高严重度问题（部分工作表失败误报 `OK`、LLM 增强后分块失步），以及 2 个中严重度问题（clean 阶段丢弃引擎结构、0-chunk 误报 `OK`）。全部 357 个测试通过，mypy 0 错误。

## ⚠️ 状态语义修复（A1 / B4）

### 部分工作表失败被误报为 `OK`（A1，高严重度）

`DeepEngine._result_multi` 在处理 Excel 时，若**部分**工作表损坏（`sheets` 非空 + `errors` 非空），原先只 `add_warning` 而不改 `status`——默认值 `OK` 保持不变。后果链：

- `DocumentResult.success` = `status ∈ (OK, DEGRADED) and (markdown or chunks)` → 部分失败时 `success=True`
- CLI 退出码只看 `success`（`cli.py L186`）→ 损坏的 `.xlsx` 也返回 **exit 0**
- 与项目自身文档化的 `OK / DEGRADED / ERROR` 三态契约冲突

**修复**：`_result_multi` 在 `built["errors"]` 非空时显式 `result.status = ConversionStatus.DEGRADED`。CLI 现在对部分失败文件返回 exit 0 但 `success` 仍为 True（DEGRADED 语义），`warnings` 中列出失败工作表。全表失败仍走 `ERROR` 分支（不变）。

### 0-chunk 误报 `OK`（B4，中严重度）

启用分块却产出 0 个 chunk（文档非空）时，原先只 `add_warning` 不改 `status`。后果：用户拿到 `success=True` 但 RAG 索引为空——静默功能失败。

**修复**：`ProcessingPipeline._chunk` 在检测到非空文档产出 0 chunk 时，`status` 从 `OK` 降为 `DEGRADED`。`success` 仍为 True（markdown 存在，可降级使用）。

## 🔁 RAG 一致性增强（A2 / B1）

### LLM 增强后分块失步（A2，高严重度）

Pipeline 顺序是 `clean → chunk → enhance`。`LlmEnhancer.enhance` 把图片描述插入 `result.markdown`（**在 chunk 之后**），但**不重分块**。后果：启用"分块 + LLM"时，`result.chunks` 仍是增强前切分的——下游 RAG 检索不到新插入的描述文本。

**修复**：

- `ProcessingPipeline.run` 在 `_enhance` 后比较 `markdown` 前后（`markdown_before`），若增强器实际改写了文档且 `result.chunks` 非空，调用新增的 `_rechunk_if_stale` 重分块。
- 无改写（无描述图 / LLM 关闭 / offline）时是 no-op。
- 新增 `_rechunk_if_stale` 方法，复用 `chunker_factory`，异常降级（不中断批次）。

### clean 阶段丢弃引擎结构（B1，中严重度）

`ProcessingPipeline._clean` 原先 `result.document = Document(text=cleaned)` 只保留文本，**丢弃引擎填充的 `elements` 与 `metadata`**。后果：`MarkdownChunker` 声称的"header-aware 分块（基于 `doc.elements`）"契约**在产品流程中从未生效**——clean 后 `elements` 总为空，chunker 永远走文本重解析降级路径。

**修复**：

- `_clean` 重建 `Document` 时保留 `elements`（`list(result.document.elements)`）与 `metadata`（`dict(result.document.metadata)`）。
- `LlmEnhancer.enhance` 重建 `Document` 时同样保留（避免与 B1 冲突——增强器若在 clean 后丢弃结构，B1 的修复会被抵消）。
- `None` document 场景安全（返回空 `elements` / `metadata`）。
