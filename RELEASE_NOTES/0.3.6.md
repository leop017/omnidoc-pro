# v0.3.6 — 零风险修复：WordBuilder suffix 字段对齐 docx（_word.py）

**OmniDoc Pro** v0.3.6 包含 1 项零风险缺陷修复。全套测试 **404 passed** 保持不变。

## 🔧 修复清单（1 项）

### 1. 📄 `WordBuilder.build`：返回 dict 中 `suffix` 字段由 `"doc"` 改为 `"docx"`（_word.py）

**问题**：`WordBuilder.build` 使用 `python-docx` 解析 `.docx` 文件，但返回的 dict 中 `suffix` 字段错误地写成 `"doc"`。该字段被 `_exporters.py` 的 `write_markdown` 用于拼接输出文件名（`{stem}.{suffix}.md`），导致输出文件名为 `.doc.md` 而非 `.docx.md`。

**修复**：`"suffix": "doc"` → `"suffix": "docx"`，与 `metadata["format"]` 及输入文件扩展名保持一致。

**风险 = 0 的论证**：
- 仅影响输出文件名的后缀拼写（`report.doc.md` → `report.docx.md`）；
- 所有现有测试通过（404 passed），无测试依赖旧的后缀字符串；
- 下游 chunker / cleaner 只处理 `content` 字段，不受影响。
