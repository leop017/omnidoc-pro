# v0.1.2 — 发布流程完善 + 文档维护

**OmniDoc Pro** v0.1.2 是在 0.1.1 基础上的修订版本，主要完善了 CI 发布流程、修正了文档与代码的不一致，并让 PyPI 页面能正确渲染 README 描述。

## 改进（CI / 发布流程）

- **`workflow_dispatch` 手动触发修复**（`.github/workflows/release.yml`、`publish-pypi.yml`）
  两个 workflow 的 `workflow_dispatch` 输入 `ref` 原先未生效（Checkout 总是检出 main）。现 `actions/checkout` 增加 `ref: ${{ inputs.ref }}` + `fetch-depth: 0`，手动 Run workflow 填任意 tag 即可正确构建该 tag 的内容。
- **`publish-pypi.yml` 去除诊断 token 输出**：移除 CI 日志中打印 `PYPI_API_TOKEN` 长度/前缀的临时诊断行，避免 token 元信息泄露。
- **`pyproject.toml` 新增 `readme` 字段**（`readme = "README.md"` + `readme-type = "text/markdown"`）：让 PyPI 页面自动渲染 README 描述（0.1.1 构建时尚无此字段，故 PyPI 描述为空，本版起生效）。

## 文档（Documentation）

- **README 发布章节修正**：secret 名 `PYPI_TOKEN` → `PYPI_API_TOKEN`（与实际 workflow 一致）；补充手动 Run workflow + `ref` 参数说明；新增「无 Python 环境？直接下 exe」章节指向 GitHub Releases；bump 提示明确 `pyproject.toml` 与 `__init__.py` 两处版本号需保持一致。
- **README 版本号** `0.1.1` → `0.1.2`。
- **`RELEASE_NOTES/README.md`** 索引新增 0.1.2。

## 测试

全量测试通过：**281 passed, 6 subtests passed**。

## 已知限制

- exe 仍为 Windows 构建（CLI / WebUI）；Linux/macOS 请通过 `pip install` 安装 Python 版本。
- LLM 增强功能需自行配置 API key（OpenAI / Ollama / 兼容 API）。
